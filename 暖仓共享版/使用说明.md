# 暖仓 · 家庭共享版

## 怎么用

1. 双击 `启动暖仓.bat`。
2. 浏览器自动打开 `http://127.0.0.1:8787`。
3. 手机连同一个 Wi-Fi，在浏览器输入窗口里显示的「手机 / 平板」地址。

关掉黑色窗口，共享就停了。数据已经写进 `数据\暖仓数据.json`。

## 和单机版的区别

- 单机版数据存在浏览器本地，只有这台电脑能看。
- 这个版本由这台电脑统一保管数据。同一 Wi-Fi 下的手机、平板、电脑打开同一地址，看到的是同一份数据。
- 一台设备改完，其他设备 4 秒内自动同步。
- 不用账号、不用密码、不连外网。

## 数据放在哪

- 数据文件：`数据\暖仓数据.json`，每次保存留一份 `.bak`。
- 导出备份：页面「设置与备份」→「导出备份 JSON」。
- 旧数据：首次启动时，如果 `..\暖仓发布\暖仓数据.json` 有内容、本目录还没有数据，会自动接管。

## 手机打不开

1. 确认手机和电脑连的是同一个 Wi-Fi。
2. 首次启动时 Windows 可能弹出防火墙提示，选「允许访问」。
3. 电脑上的黑窗口关掉就打不开，重新双击 `启动暖仓.bat`。
4. 8787 端口被占用时，服务会自动改用 8788、8789，以窗口里打印的地址为准。

## 标签打印

「标签中心」→ 勾选箱子 → 「打印标签页」。标签 50×30 mm，A4 每页 24 张，浏览器打印时选 A4、100% 比例。

## 云端版（可选）

地址后面加 `?mode=cloud`，例如 `http://127.0.0.1:8787/?mode=cloud`。用邮箱和密码登录，数据存到 Supabase，换设备也能看到同一份。

启用前要在 Supabase 后台做 3 件事：跑建表授权 SQL、确认邮箱登录、按需配 GitHub。步骤见 `后台操作清单.md`。

- 云端模式和局域网模式共用同一个页面，数据来源不同，不要同时用两个模式写同一批箱子。
- 页面不加载任何外部脚本，GitHub 直连不通时用邮箱登录即可。
