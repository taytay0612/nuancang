## 请求路径

浏览器 → `https://<站点>.netlify.app/sb/*` → Netlify 按 `_redirects` 反代 → Supabase。

页面和接口同域，浏览器不直接访问 `supabase.co`。手机 Wi-Fi 到不了 `supabase.co` 也能用。

- `_redirects` 必须放在部署根目录，且结尾要有换行，否则 Netlify 会整份忽略。
- 部署清单：`index.html` + `_redirects` 两个文件，用 `暖仓公网版.zip` 一次传。

## 已知问题

- GitHub 登录按钮在本网络不可用，用邮箱密码。
